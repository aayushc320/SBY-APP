StrongByYoga API

API Status: Active

This is the backend API server for StrongByYoga platform. If you're seeing this page, it means the API server is running correctly.

The frontend application should be accessing this API. If you intended to view the StrongByYoga application, please go to: StrongByYoga Frontend

Available Endpoints

GET /api/users - Get all users (Admin only)
GET /api/mongodb/users - Get all users from MongoDB (For admin panel)
POST /api/auth/login - User login
POST /api/auth/register - User registration
